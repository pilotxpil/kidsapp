# יצירת חבילות לימוד ל־KidsQuest (לייבוא באפליקציה)

מסמך זה מיועד להדבקה ל־AI (או לעבודה ידנית) כדי לייצר קובץ JSON תקין שניתן לייבא במסך **לימוד → ייבוא מקובץ** באפליקציית ההורה.

**בדיקה, עריכה וטעינה למאגר:** פתחו http://localhost:3001/learning/studio (כשה־API רץ) או את [`learning-pack-studio.html`](./learning-pack-studio.html). מתחברים כהורה, בוחרים מאגר **האפליקציה (ייצור)** או מקומי, ומקישים «טעינה למאגר» — בלי להעביר קובץ לטלפון.

---

## הוראה להעתקה ל־AI

העתק/י את הבלוק הבא כלשונו, והשלם/י בסוף את נושא החבילה, הכיתה, והשפה:

```
את/ה מייצר/ת חבילת לימוד עבור אפליקציית KidsQuest.
הפלט חייב להיות JSON תקין בלבד (בלי markdown, בלי הסברים מסביב) — אובייקט אחד, או מערך של עד 20 אובייקטים.

חוקים מחייבים:
1. כל שדות הטקסט לילד בעברית בתוך title.he / prompt.text / options[].text / passage.he (אלא אם category הוא "english" — אז שאלות ותשובות באנגלית, וכותרת title.he בעברית קצרה שמסבירה את הנושא).
2. category חייב להיות אחד מ: "language" | "math" | "english" | "science" | "general"
3. kind: "quiz" (ברירת מחדל) או "reading"
4. אם kind="reading" — חובה passage.he (טקסט רציף לקריאה) ורצוי passageTitle.he
5. version: מספר שלם >= 1 (מומלץ 1)
6. defaultPoints: נקודות שמתקבלות **פעם אחת בסיום כל החבילה** (לא לפי כמה שאלות נכונות). מספר שלם 1–100 (מומלץ 10–25, כמו משימה)
7. grade: מספר 1–6 (א=1 … ו=6) כשהתוכן מותאם לכיתה
8. id: מחרוזת באנגלית kebab-case, ייחודית, למשל "math-fractions-compare-4". המערכת תהפוך אותה אוטומטית ל-custom_... בייבוא.
9. activities: מערך לא ריק. נתמך type="multiple_choice" או type="select_all" או type="open_words"
10. לכל שאלה:
    - id ייחודי בתוך החבילה (q1, q2, …)
    - לפחות 2 אפשרויות ב-multiple_choice (מומלץ 3–4)
    - select_all: לפחות 3 אפשרויות, לפחות 2 תשובות נכונות, ולפחות אחת שגויה
    - לכל אפשרות id קצר ייחודי ("a","b","c",…) ו-text
    - multiple_choice: answer הוא ה-id של האפשרות הנכונה (לא הטקסט!)
    - select_all: answer הוא מערך id-ים, למשל ["a","c"]
    - open_words: שאלת הכנסת מילים. חובה accept (כל המילים הקבילות) ו-count (כמה למצוא). אפשר aliases עם | למשל "חזרה|חזר"
    - שאלות select_all / open_words מסומנות אוטומטית לילד לפי ה-type
11. explanation.he אופציונלי אבל מומלץ (להורה בסקירה)
12. בלי שדות מיותרים, בלי פסיקים אחרונים לא תקינים, בלי תגובות מחוץ ל-JSON

תבנית מינימלית ל-quiz:
{
  "id": "topic-slug-grade",
  "version": 1,
  "title": { "he": "כותרת בעברית" },
  "category": "math",
  "kind": "quiz",
  "grade": 4,
  "tags": ["topic"],
  "defaultPoints": 5,
  "activities": [
    {
      "id": "q1",
      "type": "multiple_choice",
      "prompt": { "text": "השאלה?" },
      "options": [
        { "id": "a", "text": "אפשרות 1" },
        { "id": "b", "text": "אפשרות 2" },
        { "id": "c", "text": "אפשרות 3" }
      ],
      "answer": "b",
      "explanation": { "he": "למה זו התשובה הנכונה" }
    }
  ]
}

תבנית ל-reading (הבנת הנקרא):
- אותו מבנה, עם "kind": "reading"
- חובה: "passage": { "he": "..." }
- רצוי: "passageTitle": { "he": "..." }
- השאלות חייבות להישען על הטקסט ב-passage

איכות פדגוגית:
- רמה מתאימה לכיתה שצוינה
- multiple_choice: תשובה אחת נכונה ברורה; מסיחים סבירים אבל לא מטעים באופן לא הוגן
- אפשר לשלב select_all (כל הנכונות) ו-open_words (הכנסת מילים מהטקסט, למשל פעלים)
- בלי אלימות / תוכן לא מתאים לילדים
- 6–10 שאלות לחבילה (אלא אם ביקשו אחרת)

עכשיו צור חבילה לפי הבקשה הבאה:
[כאן לנושא / כיתה / מספר שאלות / quiz או reading]
```

## סכימה מלאה (לעיון)

| שדה | חובה | סוג | הערות |
|-----|------|-----|--------|
| `id` | כן | string | באנגלית, ייחודי. בייבוא יקבל קידומת `custom_` אם חסרה |
| `version` | מומלץ | number ≥ 1 | אם חסר בייבוא → 1 |
| `title.he` | כן | string | שם החבילה שמוצג להורה ולילד |
| `title.en` | לא | string | אופציונלי |
| `category` | כן | enum | `language` (עברית), `math`, `english`, `science`, `general` |
| `kind` | לא | enum | `quiz` (ברירת מחדל) או `reading` |
| `passage.he` | ל־reading | string | טקסט לקריאה; חובה כש־`kind=reading` |
| `passageTitle.he` | לא | string | כותרת לטקסט |
| `grade` | מומלץ | 1–6 | כיתה א–ו |
| `tags` | לא | string[] | לתיוג/חיפוש |
| `defaultPoints` | כן | number ≥ 1 | נקודות לסיום החבילה. לא תלוי במספר התשובות הנכונות |
| `activities` | כן | array | לפחות פעילות אחת |

### פעילות `select_all` (סמנו את כל הנכונות — מתאים במיוחד להבנת הנקרא)

| שדה | חובה | הערות |
|-----|------|--------|
| `id` | כן | ייחודי בחבילה |
| `type` | כן | `"select_all"` |
| `prompt.text` | כן | נוסח השאלה |
| `options` | כן | ≥ 3 פריטים עם `id` + `text` |
| `answer` | כן | מערך של לפחות שני `options[i].id`. אסור שכל האפשרויות יהיו נכונות |
| `explanation.he` | לא | מומלץ |

```json
{
  "id": "q3",
  "type": "select_all",
  "prompt": { "text": "מה נכון לפי הטקסט?" },
  "options": [
    { "id": "a", "text": "עובדה מהטקסט" },
    { "id": "b", "text": "עובדה נוספת מהטקסט" },
    { "id": "c", "text": "פרט שלא מופיע" },
    { "id": "d", "text": "עוד עובדה מהטקסט" }
  ],
  "answer": ["a", "b", "d"],
  "explanation": { "he": "ג לא מופיע בטקסט." }
}
```

### פעילות `multiple_choice` (תשובה אחת)

| שדה | חובה | הערות |
|-----|------|--------|
| `id` | כן | ייחודי בחבילה |
| `type` | כן | תמיד `"multiple_choice"` |
| `prompt.text` | כן | נוסח השאלה |
| `options` | כן | ≥ 2 פריטים עם `id` + `text` |
| `answer` | כן | חייב להיות `options[i].id` קיים |
| `explanation.he` | לא | מומלץ לסקירת הורה |

```json
{
  "id": "q1",
  "type": "multiple_choice",
  "prompt": { "text": "כמה זה 7 × 8?" },
  "options": [
    { "id": "a", "text": "54" },
    { "id": "b", "text": "56" },
    { "id": "c", "text": "63" }
  ],
  "answer": "b",
  "explanation": { "he": "7×8=56." }
}
```

### פעילות `open_words` (הכנסת מילים מהטקסט)

הילד מקליד `count` מילים שונות. ב־`accept` רשימת **כל** המילים הקבילות (למשל כל הפעלים בטקסט). כל מילה שהילד מכניס חייבת להתאים לפריט שעוד לא נוצל. אחרי בדיקה מוצגת רשימת המילים הקבילות.

| שדה | חובה | הערות |
|-----|------|--------|
| `id` | כן | ייחודי בחבילה |
| `type` | כן | `"open_words"` |
| `prompt.text` | כן | למשל «מצאו 3 פעלים בסיפור» |
| `count` | כן | כמה מילים למצוא (1–8). חייב להיות ≤ אורך `accept` |
| `accept` | כן | כל המילים הקבילות. aliases של אותה מילה: `"חזרה|חזר"` |
| `explanation.he` | לא | מומלץ |

```json
{
  "id": "q4",
  "type": "open_words",
  "prompt": { "text": "מצאו 3 פעלים בטקסט" },
  "count": 3,
  "accept": ["רצה|רץ", "פתח", "אמרה|אמר", "ישבה", "חייכה"],
  "explanation": { "he": "פעלים מהטקסט: רצה, פתח, אמרה, ישבה, חייכה." }
}
```

סוגים `fill_blank` / `flashcard` קיימים בקוד אבל **לא** עוברים ולידציה בייבוא — אל תייצרו אותם לקובץ ייבוא.

## ייבוא באפליקציה

1. שמרו את הפלט לקובץ `.json` (או העתיקו ללוח).
2. באפליקציית **הורה** → **לימוד** → **ייבוא מקובץ**.
3. אפשר לייבא אובייקט בודד או מערך: `[{...}, {...}]` (עד 20 חבילות).
4. אחרי ייבוא מוצלח החבילה מופיעה בקטלוג עם תג «שלי», ואפשר לשייך לילדים / לערוך / לייצא.

### כשלונות נפוצים

| בעיה | תוצאה |
|------|--------|
| `answer` הוא הטקסט במקום ה־`id` | החבילה נדחית |
| פחות מ־2 אפשרויות | נדחית |
| `kind: "reading"` בלי `passage.he` | נדחית |
| `category` לא מהרשימה | נדחית |
| `type` שאינו `multiple_choice` / `select_all` / `open_words` | נדחית |
| `select_all` עם פחות משתי תשובות נכונות | נדחית |
| `open_words` בלי `accept` / `count`, או `count` גדול מאורך `accept` | נדחית |
| JSON לא תקין (פסיק אחרון, גרשיים חסרים) | שגיאת ייבוא |
| יותר מ־20 חבילות במערך אחד | נדחה |

## טיפ לבקשות חוזרות ל־AI

אחרי שה־AI ייצר JSON, אפשר לבקש:

> ודא שוב: כל `answer` שווה ל־`id` של אפשרות קיימת; יש לפחות 6 שאלות; JSON תקין בלבד בלי טקסט מסביב.
